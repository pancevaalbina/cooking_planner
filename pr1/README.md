# Планировщик приготовления нескольких блюд

## Назначение
Приложение помогает приготовить несколько блюд так, чтобы все они были
готовы к одному времени. По времени подачи и длительности рецептов оно
рассчитывает, когда начинать каждое блюдо.

## Целевая аудитория
Домашние повара, которые готовят праздничный ужин или обед из нескольких
блюд; начинающие кулинары, которым трудно рассчитать время.

## Предметная область
Кулинария и планирование времени: блюда, рецепты, задачи приготовления
(нарезка, варка, запекание) и их длительность.

## Основные сущности
- блюдо (название, количество порций);
- рецепт (ингредиенты, описание);
- задача (шаг рецепта, длительность, активная или пассивная);
- время (время подачи, время начала готовки).

## Основные функции
- расчет общего времени приготовления блюда;
- расчет времени начала готовки по времени подачи;
- форматирование длительности (часы и минуты);
- определение статуса: успеваем ли мы приготовить блюдо вовремя.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
